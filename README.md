Konverrt
===========

Konverrt is a small library intended to simplify conversion of Rust `Result`s into HTTP responses.

Konverrt is supposed to be used with [axum](https://crates.io/crates/axum) and [utoipa](https://crates.io/crates/utoipa), although bindings to them may become controlled via corresponding features over time.
